# Sistema de Gestión de Inventario (Python)

Este es un software sencillo diseñado para registrar y gestionar productos en un inventario. Permite a los usuarios ingresar datos de productos de manera segura mediante validaciones de entrada en tiempo real.

##  Características

* **Interfaz de menú:** Navegación simple y amigable mediante opciones numéricas.
* **Validación de datos:** Uso de bloques `try-except` para asegurar que el precio y la cantidad sean valores numéricos válidos.
* **Cálculo automático:** Determina el costo total del stock ingresado por cada artículo.
* **Control de errores:** El sistema no permite valores negativos para precios o cantidades, garantizando la integridad de los datos.

Python 3.x
